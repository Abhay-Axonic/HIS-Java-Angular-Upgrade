The DAO rethrows cleanly, but the controller's catch is EMPTY (UnitServiceTariffMasterController:51-52), so the exception is swallowed into {{ '{' }}status: error, code: null, message: null{{ '}' }} with HTTP 200. The ForWeb variant (its DAO uses the no-op placeholder IN (1)) works — this rebuild calls it.

Not fixed (Rule 10 — backend BR candidate; the fix pattern is the ForWeb DAO's placeholder).
